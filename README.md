# MediPredict AI

MediPredict AI is a machine learning-based disease prediction and health recommendation system. It predicts potential diseases based on symptoms provided by the user and provides relevant health information such as disease descriptions, precautions, medications, diet recommendations, and workout suggestions.

## Features

- Disease prediction based on user symptoms
- Machine learning-based classification
- Disease description
- Recommended precautions
- Medication suggestions
- Diet recommendations
- Workout recommendations
- Flask-based web application
- Interactive user interface

## Tech Stack

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS
- Machine Learning

## How It Works

1. User enters symptoms.
2. Symptoms are converted into a feature vector.
3. The trained machine learning model predicts the most likely disease.
4. The application retrieves relevant information from the datasets.
5. The results are displayed through the Flask web interface.
